## 10. Database Integration Architecture Guide
To connect a database to the DEVYRO stack for lead management, user authentication, or dynamic content:

### Option A: Supabase (Recommended — Serverless PostgreSQL)
1. Sign up at https://supabase.com and create a project.
2. Install the client: `npm install @supabase/supabase-js`.
3. Add environment variables in `.env.local`:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=https://xyzcompany.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGciOi...
   SUPABASE_SERVICE_ROLE_KEY=eyJhbGciOi...
   ```
4. Create client `lib/supabase.js`:
   ```javascript
   import { createClient } from '@supabase/supabase-js';
   export const supabase = createClient(
     process.env.NEXT_PUBLIC_SUPABASE_URL,
     process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY
   );
   ```
5. Insert leads / data from API route:
   ```javascript
   const { data, error } = await supabase.from('leads').insert([
     { name, email, phone, requirements }
   ]);
   ```
6. Kotlin Android integration:
   Use `io.github.jan-tennert.supabase:postgrest-kt` or direct HTTPS API calls via Ktor.
