## 🚀 Getting Started Locally

### Prerequisites
- Node.js (v18+ recommended)
- npm or yarn

### Quick Start
```bash
# Clone the repository
git clone https://github.com/aditiwary/DEVYRO.git
cd DEVYRO

# Install dependencies
npm install

# Start local development server
npm run dev
# or
node server.js
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the live studio site.
