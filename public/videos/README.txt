# DEVYRO VIDEO REFERENCES DIRECTORY
# ==================================

Place your reference video files here:
- Supported formats: .mp4, .webm, .mov, .m4v, .mkv
- Location: public/videos/ (or directly in public/)

Once you add your video files:
1. The local server automatically detects them via http://localhost:3000/api/videos
2. The DEVYRO live preview page will display them in the Reference Stage.
3. You can notify me, and I can inspect them frame-by-frame to generate the precise prompt and transform the website into your desired layout!
